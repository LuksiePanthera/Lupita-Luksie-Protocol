# Lupita-Luksie Protocol
## Zenith Calibration Kit

This project maps the sky to the ground. 

Lupita Island (7.5°S) sits directly under the star Rigel (-8.2° dec) and the Witch Head Nebula (-7.9° dec). This means these celestial objects pass almost exactly at the Zenith (directly overhead) every night. 

This creates a perfect, natural calibration point for telescopes, spectroscopy, and clock synchronization.

**This creates a predictable, repeatable, verifiable reference point.**


**A foundational geometric reference for global builders.**

## Who is this for?

### 🛠️ If you have hardware (telescope, camera, GPS)

Run `src/rigel-zero.py`. It tells you the exact second to point your telescope straight up to catch Rigel at its clearest.

### 📊 If you have NO hardware (just a laptop)

Run `src/rigel-visualizer.py`. It plots Rigel's path across the sky on any date from your location. No telescope needed. You can:
- See the geometry in action
- Understand how the Zenith alignment works
- Practice astronomical calculations
- Learn without spending a cent

### 📖 If you have curiosity (no laptop, no hardware)

Read this README. Understand the geometry. Share the concept. The math is free.

## What this kit includes

1. **`src/rigel-zero.py`** - For people with hardware. Calculates the exact time Rigel passes the Zenith from your location. Saves you 45 minutes of math.

2. **`src/rigel-visualizer.py`** - For people WITHOUT hardware. Plots Rigel's path across the sky. Just a laptop needed.

3. **`docs/hardware.md`** - A 1-page shopping list for building a physical calibration kit (telescope + GPS + camera).
