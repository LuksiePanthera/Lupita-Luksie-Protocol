# Lupita-Luksie Protocol
## Hardware Kit Shopping List

To replicate the physical setup, you need these 5 things:

### 1. Telescope
- Any motorized equatorial mount
- Aperture: 8" (200mm) or larger recommended
- Example: Celestron 8" SCT or equivalent

### 2. Camera
- Astro-modified DSLR (e.g., Canon 60Da)
- Or any CMOS guide camera
- Must be able to take long exposures

### 3. Spectrometer (optional but recommended)
- StarAnalyzer 200 diffraction grating
- Or any slit spectrometer

### 4. GPS Clock
- GPS module with 1PPS output
- Example: Adafruit Ultimate GPS Breakout
- Ensures microsecond timestamp accuracy

### 5. Laptop
- Runs Python 3.9 or higher
- With `astropy`, `numpy`, and `matplotlib` installed

### No hardware? No problem.

Run `src/rigel-visualizer.py` on your laptop. You will see Rigel's path across the sky. No telescope needed.
