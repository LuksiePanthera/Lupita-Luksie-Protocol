# How to Contribute

**This is an open invitation.**

## Questions?
- Open an **Issue** on GitHub. I check them when I can.
- If you know the answer to someone else's question, answer it.

## Improvements?
- Fork this repository.
- Make your changes.
- Submit a **Pull Request**.
- If I like it, I merge it. If I don't, I will explain why.

## Collaboration?
- Open an Issue with the tag "collaboration".
- Tell me what you are building.
- I will join if I can.

## Code of Conduct
- Be kind.


**I am not a full-time maintainer. I am a host. Contribute at your own pace, and I will do the same.**
